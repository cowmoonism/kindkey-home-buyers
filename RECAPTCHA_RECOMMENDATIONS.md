# Рекомендации по использованию reCAPTCHA v3

## ✅ Да, имеет смысл использовать reCAPTCHA для защиты от ботов

### Почему это важно:

1. **Защита от спама и ботов**
   - Предотвращает автоматические отправки форм
   - Защищает от массовых атак на форму
   - Фильтрует некачественные лиды

2. **Экономия ресурсов**
   - Меньше ложных заявок = меньше обработки
   - Экономия времени на проверке лидов
   - Снижение нагрузки на сервер

3. **Улучшение качества лидов**
   - Только реальные пользователи проходят проверку
   - Выше конверсия в продажи
   - Меньше времени на обработку спама

## 🎯 Текущая реализация (уже работает)

### Что у вас уже есть:

✅ **reCAPTCHA v3** - невидимая защита (не требует действий от пользователя)
✅ **Проверка на сервере** - токен валидируется через Google API
✅ **Score-based защита** - проверка по рейтингу (score > 0.5)
✅ **Graceful degradation** - форма работает даже без reCAPTCHA (для dev)

### Как это работает:

1. **На клиенте (LeadForm.tsx):**
   - reCAPTCHA загружается автоматически
   - При отправке формы генерируется токен
   - Токен отправляется вместе с данными формы

2. **На сервере (api/lead/route.ts):**
   - Токен проверяется через Google API
   - Проверяется score (рейтинг от 0.0 до 1.0)
   - Если score < 0.5, запрос отклоняется

## 📊 Рекомендации по настройке

### 1. Порог score (текущий: 0.5)

**Рекомендации:**

- **0.5-0.7** - стандартный порог (текущая настройка)
- **0.7-0.9** - строгая защита (может блокировать реальных пользователей)
- **< 0.5** - слабая защита (больше ботов пройдет)

**Текущая настройка (0.5) - оптимальна** ✅

### 2. Мониторинг score

**Рекомендуется:**

- Логировать score для анализа
- Отслеживать средний score пользователей
- Настраивать порог на основе данных

**Текущая реализация:**

```typescript
// В lib/captcha.ts уже есть проверка score
return data.success && (data.score || 0) > 0.5;
```

### 3. Обработка ошибок

**Текущая реализация хороша:**

- Если reCAPTCHA не настроена - форма работает (dev mode)
- Если проверка не прошла - показывается ошибка
- Пользователь может повторить отправку
