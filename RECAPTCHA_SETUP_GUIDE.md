# 🔒 Настройка reCAPTCHA v3

## ✅ Зачем нужен reCAPTCHA?

reCAPTCHA v3 защищает форму от ботов и спама:

- ✅ Невидимая защита (пользователь ничего не видит)
- ✅ Проверка на сервере (безопасно)
- ✅ Оценка по рейтингу (score от 0.0 до 1.0)
- ✅ Блокирует ботов автоматически

## 🚀 Пошаговая инструкция

### Шаг 1: Создание reCAPTCHA ключей

1. **Откройте Google reCAPTCHA Admin Console:**
   - Перейдите: https://www.google.com/recaptcha/admin

2. **Войдите в Google аккаунт** (если не вошли)

3. **Нажмите "+" (Create)** для создания нового сайта

4. **Заполните форму:**
   - **Label (Название):** KindKey Home Buyers (или любое другое)
   - **reCAPTCHA type:** Выберите **reCAPTCHA v3** ⚠️ Важно: именно v3!
   - **Domains:** Добавьте ваш домен:
     - `kindkeyhomebuyers.com`
     - `www.kindkeyhomebuyers.com` (если используется)
     - `*.render.com` (для тестирования на Render)
5. **Примите условия использования** (Accept reCAPTCHA Terms of Service)

6. **Нажмите "Submit"**

7. **Скопируйте ключи:**
   - **Site Key** (публичный ключ) - это `NEXT_PUBLIC_RECAPTCHA_SITE_KEY`
   - **Secret Key** (секретный ключ) - это `RECAPTCHA_SECRET_KEY`

   ⚠️ **Важно:** Сохраните оба ключа в безопасном месте!

### Шаг 2: Добавление ключей в Render

1. **Зайдите в Render Dashboard**
2. **Откройте ваш сервис** (web service)
3. **Перейдите в раздел "Environment"** (Environment Variables)
4. **Добавьте две переменные:**

   ```
   NEXT_PUBLIC_RECAPTCHA_SITE_KEY=ваш_site_key_из_Google
   RECAPTCHA_SECRET_KEY=ваш_secret_key_из_Google
   ```

   **Пример:**

   ```
   NEXT_PUBLIC_RECAPTCHA_SITE_KEY=6LcXXXXXXXXXXXXX-XXXXXXXXXXXXX
   RECAPTCHA_SECRET_KEY=6LcXXXXXXXXXXXXX_XXXXXXXXXXXXX
   ```

5. **Сохраните изменения**
6. **Render автоматически перезапустит сервис**

### Шаг 3: Проверка работы

1. **Откройте ваш сайт**
2. **Заполните форму**
3. **Отправьте форму**
4. **Проверьте:**
   - Форма должна отправляться нормально
   - В консоли браузера не должно быть ошибок reCAPTCHA
   - Боты должны блокироваться автоматически

## 📋 Что нужно добавить в Render

**Две переменные:**

1. **NEXT_PUBLIC_RECAPTCHA_SITE_KEY**
   - Публичный ключ (виден в браузере)
   - Используется на клиенте для генерации токена
   - Формат: `6LcXXXXXXXXXXXXX-XXXXXXXXXXXXX`

2. **RECAPTCHA_SECRET_KEY**
   - Секретный ключ (скрыт от пользователей)
   - Используется на сервере для проверки токена
   - Формат: `6LcXXXXXXXXXXXXX_XXXXXXXXXXXXX`

## ⚠️ Важные моменты

### Публичный vs Секретный ключ

- **NEXT_PUBLIC_RECAPTCHA_SITE_KEY** - начинается с `NEXT_PUBLIC_` потому что используется в браузере
- **RECAPTCHA_SECRET_KEY** - секретный, используется только на сервере

### Домены в reCAPTCHA

При создании reCAPTCHA добавьте:

- `kindkeyhomebuyers.com`
- `www.kindkeyhomebuyers.com` (если используется)
- `*.render.com` (для тестирования на Render)

### Что если не добавить ключи?

Код работает и без ключей (graceful degradation):

- Форма будет работать
- Но защиты от ботов не будет
- В логах будут предупреждения

**Рекомендация:** Обязательно добавьте ключи для продакшена!

## 🔧 Устранение проблем

### Проблема: "reCAPTCHA verification failed"

**Решения:**

- Проверьте правильность `RECAPTCHA_SECRET_KEY` в Render
- Убедитесь, что домен добавлен в настройки reCAPTCHA
- Проверьте логи в Render на наличие ошибок

### Проблема: reCAPTCHA не загружается

**Решения:**

- Проверьте правильность `NEXT_PUBLIC_RECAPTCHA_SITE_KEY`
- Убедитесь, что домен добавлен в настройки reCAPTCHA
- Проверьте консоль браузера на наличие ошибок

### Проблема: "Invalid site key"

**Решения:**

- Проверьте, что используете правильный Site Key
- Убедитесь, что домен добавлен в настройки reCAPTCHA
- Проверьте, что используете reCAPTCHA v3 (не v2!)

## 📊 Мониторинг reCAPTCHA

### Где посмотреть статистику?

1. Зайдите в https://www.google.com/recaptcha/admin
2. Выберите ваш сайт
3. Посмотрите статистику:
   - Количество запросов
   - Средний score
   - Процент блокировок

### Что такое score?

- **0.0 - 0.3** - вероятно бот (блокируется)
- **0.3 - 0.7** - подозрительно (может блокироваться)
- **0.7 - 1.0** - вероятно человек (разрешается)

**Текущая настройка:** score > 0.5 (оптимально)
