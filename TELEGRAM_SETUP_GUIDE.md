## 🚀 Пошаговая инструкция

### Шаг 1: Создание Telegram бота

1. **Откройте Telegram** на любом устройстве
2. **Найдите бота @BotFather** (официальный бот для создания ботов)
3. **Начните диалог** с @BotFather
4. **Отправьте команду:** `/newbot`
5. **Введите имя бота** (например: `KindKey Home Buyers Bot`)
6. **Введите username бота** (должен заканчиваться на `bot`, например: `kindkey_buyers_bot`)
7. **Скопируйте токен** который даст вам BotFather

**Пример токена:**

```
123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

⚠️ **Важно:** Сохраните токен в безопасном месте! Не публикуйте его в открытом доступе.

### Шаг 2: Создание группы и получение Chat ID

**Рекомендуется использовать группу** - так несколько человек смогут видеть заявки одновременно.

#### Создание группы в Telegram

1. **Откройте Telegram** на вашем устройстве
2. **Нажмите на иконку "Новое сообщение"** (или кнопку создания группы)
3. **Выберите "Новая группа"** (New Group)
4. **Добавьте участников** (можно добавить коллег, которые должны видеть заявки)
5. **Введите название группы** (например: "KindKey Home Buyers - Leads" или "Заявки с сайта")
6. **Нажмите "Создать"** (Create)

#### Добавление бота в группу

1. **Откройте созданную группу**
2. **Нажмите на название группы** (вверху экрана)
3. **Нажмите "Добавить участников"** (Add Members) или "Добавить" (Add)
4. **Найдите вашего бота** по username (который вы создали в шаге 1)
5. **Добавьте бота в группу**
6. **Важно:** Отправьте любое сообщение в группу (например: "Тест") - это нужно для активации бота

#### Получение Chat ID группы

1. **Откройте браузер** на компьютере или телефоне
2. **Перейдите по ссылке** (замените `<ВАШ_ТОКЕН>` на токен из шага 1):

   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```

   **Пример:**

   ```
   https://api.telegram.org/bot123456789:ABCdefGHIjklMNOpqrsTUVwxyz/getUpdates
   ```

3. **Вы увидите JSON ответ** - найдите в нем поле с вашей группой
4. **Найдите Chat ID группы** - это будет **отрицательное число**, например: `-1001234567890`

**Пример ответа для группы:**

```json
{
  "ok": true,
  "result": [{
    "update_id": 123456,
    "message": {
      "message_id": 1,
      "from": {...},
      "chat": {
        "id": -4845794812,  ← Это Chat ID группы (отрицательное число!)
        "title": "KindKey Home Buyers - Leads",
        "type": "group"  ← или "supergroup"
      },
      "date": 1234567890,
      "text": "Тест"
    }
  }]
}
```

**Важно о типах групп:**

- **"group"** - обычная группа (Chat ID короче, например: `-4845794812`)
- **"supergroup"** - супергруппа (Chat ID длиннее, например: `-1001234567890`)

**Оба типа работают одинаково!** Код поддерживает оба формата.

⚠️ **Важно:**

- Chat ID группы всегда **отрицательное число**
- Если вы не видите обновлений, отправьте еще одно сообщение в группу и обновите страницу
- Убедитесь, что бот добавлен в группу и вы отправили хотя бы одно сообщение

#### Альтернативный способ: Использование @RawDataBot

1. **Добавьте бота @RawDataBot** в вашу группу
2. **Отправьте любое сообщение** в группу
3. **@RawDataBot покажет информацию** о сообщении, включая Chat ID

#### Если ничего не работает

1. **Убедитесь, что бот добавлен в группу**
2. **Отправьте сообщение в группу** (любое)
3. **Подождите 1-2 секунды**
4. **Обновите страницу** с getUpdates
5. **Проверьте, что токен правильный** (без пробелов, полностью скопирован)

### Шаг 3: Добавление переменных в Render

1. **Зайдите в Render Dashboard**
2. **Откройте ваш сервис** (web service)
3. **Перейдите в раздел "Environment"**
4. **Добавьте две переменные:**

   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_из_шага_1
   TELEGRAM_CHAT_ID=ваш_chat_id_из_шага_2
   ```

   **Пример для группы:**

   ```
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
   TELEGRAM_CHAT_ID=-1001234567890
   ```

   ⚠️ **Важно:** Chat ID группы - это отрицательное число! Не забудьте знак минус.

5. **Сохраните изменения**
6. **Перезапустите сервис** (Render сделает это автоматически)

### Шаг 4: Проверка работы

1. **Заполните форму** на вашем сайте

## 🔧 Устранение проблем

### Проблема: Сообщения не приходят

**Проверьте:**

1. ✅ Токен бота правильный
   - Проверьте, что скопировали весь токен
   - Убедитесь, что нет лишних пробелов

2. ✅ Chat ID правильный
   - Для группы - **отрицательное число** (например: `-1001234567890`)
   - Убедитесь, что бот добавлен в группу
   - Убедитесь, что отправили хотя бы одно сообщение в группу
   - Проверьте, что скопировали Chat ID со знаком минус

3. ✅ Переменные добавлены в Render
   - Проверьте в Environment Variables
   - Убедитесь, что нет опечаток

4. ✅ Сервис перезапущен
   - После добавления переменных Render перезапускает автоматически
   - Проверьте логи на наличие ошибок

5. ✅ Проверьте логи в Render
   - Зайдите в раздел "Logs"
   - Ищите ошибки типа "Telegram API error"

### Проблема: "Telegram credentials not configured"

**Решение:**

- Убедитесь, что переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` установлены в Render
- Перезапустите сервис

### Проблема: "Telegram API error: 401 Unauthorized"

**Решение:**

- Проверьте правильность токена бота
- Убедитесь, что токен не истек (токены не истекают, но проверьте)

### Проблема: "Telegram API error: 400 Bad Request"

**Решение:**

- Проверьте правильность Chat ID (для группы должно быть отрицательное число!)
- Убедитесь, что бот добавлен в группу
- Убедитесь, что отправили хотя бы одно сообщение в группу после добавления бота
- Проверьте, что скопировали Chat ID полностью, включая знак минус

### Проблема: "Telegram API error: 403 Forbidden" (бот не может отправлять сообщения)

**Решение:**

- Убедитесь, что бот добавлен в группу
- Попробуйте сделать бота администратором группы (не обязательно, но может помочь)
- Отправьте команду `/start` боту в группе (если бот поддерживает команды)

## 🔄 Превращение группы в супергруппу

### Когда это происходит?

Группа автоматически превращается в супергруппу, если:

- В группе больше 200 участников
- Включены некоторые функции (например, история сообщений)
- Группа была преобразована вручную администратором

### Что изменится?

1. **Chat ID изменится!**
   - Обычная группа: `-4845794812`
   - Супергруппа: `-1001234567890` (длиннее, начинается с `-100`)

2. **Что нужно сделать:**
   - Получить новый Chat ID через `getUpdates`
   - Обновить `TELEGRAM_CHAT_ID` в Render
   - Перезапустить сервис

### Как проверить текущий тип группы?

1. Откройте `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
2. Найдите вашу группу в ответе
3. Посмотрите поле `"type"`:
   - `"group"` - обычная группа
   - `"supergroup"` - супергруппа

### Как обновить Chat ID в Render?

1. Получите новый Chat ID через `getUpdates`
2. Зайдите в Render Dashboard → ваш сервис → Environment
3. Найдите переменную `TELEGRAM_CHAT_ID`
4. Обновите значение на новый Chat ID
5. Сохраните (Render перезапустит автоматически)

### Важно!

- **Код уже поддерживает оба типа групп** - ничего менять не нужно
- Просто обновите Chat ID в Render, если группа превратилась в супергруппу
- Старый Chat ID перестанет работать после преобразования
